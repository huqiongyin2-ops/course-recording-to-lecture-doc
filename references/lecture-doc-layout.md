# 课程笔记图文排版指南

## 目标

排版服务于“快速复习”和“回到原始证据”，不追求截图数量。每张图都要回答一个问题：它补充了课件或文字无法清楚表达的什么信息？

## 文档结构

1. 课程信息卡：课程名、讲者、日期、录播与妙记链接、素材缺口。
2. 一句话摘要与知识地图：列出本节课的主线和章节关系。
3. 按主题组织的详细笔记：每章先给结论，再解释概念、推导、案例和易错点。
4. 关键公式、例题和老师强调。
5. 复习清单；仅在用户需要时附完整清理版或翻译版逐字稿。

## 图片层级

按以下优先级选图：

1. 用户提供的 PDF/PPT 原页或局部裁图，用于静态课件内容。
2. 视频中的板书、手写批注、软件操作、实验和动画完成态，用于课件之外的增量信息。
3. 没有原课件时的视频 PPT 截图，并明确标注“来源：录播”。

不要用模糊投影画面替代已有的清晰 PDF，也不要同时放入信息等价的 PDF 原页与视频截图。

## 布局选择

- 单张重点图：采用图文左右，文字约占 45%，图片约占 55%。文字说明结论、观察方法和图中增量。
- 两到三张连续步骤：等宽分栏并排，按从左到右的时间或推导顺序排列。
- 超过三张：拆成多行或分成多个知识点。若缩小后文字不可读，改用单图大图。
- 手机端复核：公式、坐标轴、界面标签和板书在常见手机宽度下仍应辨认。

若当前 `lark-doc` 能力不支持理想分栏，优先保证图片清晰度和阅读顺序，使用单图顺排并保留编号，不为视觉形式牺牲信息。

## 图注

- PDF 原图：`课件原图 PDF第12页｜需求曲线移动的三个条件`
- 板书：`课堂板书 00:42:18｜由利率平价条件推导长期汇率变化`
- 现场演示：`课堂演示 01:07:05｜验证损失开始反弹`
- 视频课件替代图：`课件截图 00:18:32｜章节知识地图（来源：录播）`

图注写“新增信息”，不写“老师在讲课”等无信息描述。PDF 原图没有录播采样时间；只有确认对应讲解位置后，才补充“对应讲解 HH:MM:SS”。

## 外语内容

默认用中文呈现课程总结和进入笔记的逐字稿片段，同时保留：

- 人名、产品名、论文名和缩写；首次出现时可给出中英文对照。
- 公式、变量、代码、命令、URL 和数字单位。
- 与截图或章节对齐所需的时间戳。

不确定的术语译法保留原文并标记待核对。不要把“翻译成中文”误解为压缩或省略信息；摘要与完整逐字稿是两个不同产物，只有用户要求时才附完整逐字稿。
